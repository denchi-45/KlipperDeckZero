# 設計メモ(仕様のやり取りの記録)

KlipperDeckZero の仕様・設計について話し合った内容と、決めたことを残す場所です。
Claude Code(ターミナル)と claude.ai(GUI)のどちらで話した内容もここに集め、
次の会話に引き継ぎます。

## 使い方

- **読むとき**: 新しい会話の最初に、このフォルダの内容を Claude に渡す。
  - claude.ai: プロジェクトに GitHub リポジトリ(`denchi-45/KlipperDeckZero` の `docs/design/`)を
    追加するか、ファイルをアップロードする。
  - Claude Code: 「`docs/design/` を読んで」と頼む。
- **書くとき**: 話がまとまったら、該当するトピックのファイルに追記する。
  - claude.ai で話した場合は、「この会話を `docs/design/<トピック>.md` の形式でまとめて」と頼み、
    出てきた文章を Claude Code に渡してコミットしてもらう。
- 決定を覆したときは、元の記述を消さずに「決定事項」に新しい日付で追記する。経緯を残すため。

## ファイルの構成

トピックごとに 1 ファイル。各ファイルは次の見出しで書く。

```markdown
# <トピック名>

最終更新: YYYY-MM-DD

## 現状            … 今のコードがどうなっているか
## 決定事項        … 日付つきで、決めたことと理由
## 検討メモ        … 比較・説明・前提知識
## 未決事項 / TODO … まだ決めていないこと、次にやること
```
